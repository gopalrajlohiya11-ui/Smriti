🔬 1. The Core Scientific Rationale: Why Machine Learning in Dementia?

Dementia is not a static condition; it is a progressive neurodegenerative syndrome with severe intra-day cognitive fluctuations (e.g., Sundowning, fatigue, and episodic lucidity). Static digital games fail dementia patients due to two catastrophic extremes:

The Failure of Static Games

The "Cognitive Wall" & Anxiety

When difficulty is static and exceeds the patient's momentary cognitive reserve, patients experience severe frustration, agitation, and task abandonment, accelerating cognitive withdrawal.

The Clinical ML Solution

Adaptive Flow & Neuroplasticity

Smriti uses ML to continuously calibrate the cognitive envelope (Yerkes-Dodson Law of Arousal). Tasks remain in the optimal "Zone of Proximal Development" to maximize synaptic stimulation without distress.

Key Clinical Objectives Solved by Smriti ML

  1. Real-Time Reaction Velocity Tracking (Δt): Millisecond latency changes in visual/auditory recall serve as a sensitive digital biomarker of microvascular ischemia weeks before gross HMSE/MMSE score drops.
  2. Longitudinal Cognitive Index (S_cog in [0, 100]): Replaces subjective caregiver recollection with standardized, objective telemetry aggregated across 7-day CST playthroughs.
  3. Zero-Barrier Regional Voice Inclusivity: Digital India Bhashini TTS synthesizes native Assamese, Bodo, and Bengali speech in the cloud, removing reliance on missing local smartphone voice packs.

🎙️ 3. Digital India Bhashini Speech & Translation Pipeline

The biggest barrier to digital healthcare in North-East India is the linguistic deficit: commercial OS platforms (Android/iOS) do not bundle native Text-to-Speech (TTS) voice models for Assamese, Bodo, Manipuri, or tribal dialects. Smriti solves this by integrating Government of India Bhashini (ULCA) speech pipelines directly in our Render ML engine.

Cloud Synthesis

Base64 WAV Audio Streaming

The microservice converts text into high-fidelity 24kHz Base64-encoded WAV/MP3 audio buffers, returned in JSON payload for instantaneous HTML5 Audio playback in browser.

Dual-Engine Resilience

Zero-Crash Fallback Protocol

If the user is offline or the Bhashini API times out (>6s), the client smoothly fails over to local Web Speech API (English/Hindi) or displays the localized Assamese notice banner.

📐 4. Core Mathematical Models & Algorithmic Formulations

Algorithm A: Dynamic CST Adaptive Difficulty (POST /get_next_difficulty)

Calculates the next starting difficulty tier D_next in {1, 2, 3, 4, 5} at the end of each game level based on reaction latency Delta_t and cumulative mistake count M:

Performance Metric Condition / Threshold Difficulty Scaling Clinical Rationale
High Precision & Speed M = 0 AND Delta_t < 3.5s D_next = min(5, D_current + 1) Elevates cognitive challenge to stimulate synaptic reserve.
Cognitive Fatigue / Stress M ≥ 3 OR Delta_t > 7.0s D_next = max(1, D_current - 1) De-escalates complexity to avoid anxiety and cognitive overload.
Steady Performance 1 ≤ M < 3 AND 3.5s ≤ Delta_t ≤ 7.0s D_next = D_current Reinforces neuroplastic stabilization in current tier.

Algorithm B: Longitudinal Cognitive Health Scoring (S_cog in [0, 100])

Synthesizes a 7-day moving window of cognitive sessions (N_games), average reaction time (Delta_t_avg), and mistake count (M_total):

Cognitive Health Score Formulation: S_raw = 80 + min(15, N_games * 3) - min(30, M_total * 2.5) - min(15, max(0, avg_reaction - 3.0) * 3) S_cog = clamp(S_raw, 40, 100) Clinical Status Classification: • S_cog >= 85 : "Stable" (Optimal CST Engagement) • 70 <= S_cog < 85 : "Mild Decline - Monitor" (Requires Caregiver Attention) • S_cog < 70 : "Significant Decline - Alert Doctor" (Triggers High-Priority Red Flag Alert)

🛡️ 6. 3-Layer Fault Tolerance & Offline Fallback Matrix

Failure Mode Primary Detector Immediate Automated Recovery User Experience Impact
Render ML Microservice Cold-Start / Latency Node.js 6000ms Axios Timeout Executes in-memory heuristic math functions in mlService.js. Instant response (<5ms); difficulty and score calculated deterministically.
Bhashini Speech API Down / Network Drop Frontend AbortController Timeout (7000ms) Falls back to browser Web Speech API (English/Hindi) or Assamese banner. Patient receives spoken voice in fallback language; no app lockup.
Complete Offline Outage (No Internet in Rural NER) Service Worker + navigator.onLine === false IndexedDB (idb) stores telemetry; local heuristics compute difficulty. 100% full gameplay offline; telemetry auto-syncs when online.
